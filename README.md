# LinguaClass 🦊

Мобильное приложение для изучения английского языка **с выбором класса (5–11)**.
Формат — короткие игровые уроки, как в Duolingo: слова, фразы, аудирование,
XP, серии дней, сердца и достижения.

Работает на **iPhone и Android** как PWA: открывается в браузере и
устанавливается на домашний экран как обычное приложение (без App Store и
Google Play), в том числе **офлайн**.

## 🌐 Постоянный адрес

**https://linguaclass-prog.github.io/linguaclass/**

Сайт размещён на GitHub Pages: HTTPS, работает 24/7, компьютер держать
включённым не нужно. Репозиторий:
https://github.com/LinguaClass-prog/linguaclass

### Как установить на телефон

**iPhone (Safari):** откройте ссылку → **Поделиться** → **На экран «Домой»**
→ **Добавить**.

**Android (Chrome):** откройте ссылку → меню **⋮** → **Установить
приложение** (или «Добавить на главный экран»).

Внутри приложения те же шаги: **Профиль** → **📲 Установить приложение**.
После первого открытия по HTTPS всё кэшируется, и приложение работает без
интернета. Прогресс хранится на устройстве.

### Как обновить сайт

Заменить файлы в репозитории на GitHub (или отправить изменения), Pages
пересоберётся автоматически за минуту. После правки `app.js`/`styles.css`
увеличьте `VERSION` в `sw.js`, чтобы у пользователей обновился кэш.

## Что внутри

| Экран | Что делает |
|---|---|
| Онбординг | выбор класса, имя, размер дневной цели |
| Главная | путь по юнитам, прогресс урока, цель дня, серия, сердца |
| Урок | 8–9 упражнений: выбор перевода, сборка предложения, пропуски, аудирование, набор текста, соединение пар |
| Результат | XP, точность, звёзды, серия, достижения |
| Словарь | все слова курса с озвучкой и поиском |
| Профиль | статистика, достижения, звук, тёмная тема, смена класса, сброс прогресса |

Везде в приложении живёт **лис-маскот**: подсказывает, подбадривает после
урока, объясняет, когда закончились сердца, и ищет слова вместе с тобой.

**Классы и программа**

- 5 класс — to be, have got, Present Simple, there is/are, лексика: знакомство, класс, еда, животные, дом, погода
- 6 класс — Present Continuous, Past Simple, going to/will, одежда и покупки, дом, хобби, путешествия
- 7 класс — неправильные глаголы, must/should, Present Perfect, путешествия, здоровье, работа, школа, праздники
- 8 класс — will/going to, пассив, косвенная речь, First Conditional, технологии, СМИ, культура, здоровье, природа
- 9 класс — Past Perfect, пассив, модальные глаголы, наука, образование, общество, технологии, искусство
- 10 класс — герундий/инфинитив, Second Conditional, экономика, карьера, экология, наука, СМИ
- 11 класс — Third Conditional, инверсия, Future Perfect, экзамен, дебаты, профессии будущего, глобальные проблемы, личный рост

В каждом классе 5 юнитов × 4 урока = **20 уроков** и 50 слов. Всего в курсе
**140 уроков** и **350 слов**. Уроки открываются последовательно: следующий —
только после предыдущего.

**Тёмная тема**

В профиле есть переключатель **🌙 Тёмная тема**. Сначала приложение
подстраивается под системную тему телефона, а выбор запоминается на
устройстве.

## Запуск

Нужен только Python 3 (без зависимостей).

```bash
# из папки linguaclass
python serve.py          # http://localhost:8000
python serve.py 4173     # другой порт
```

На Windows проще дважды кликнуть **`start.bat`**.

Сервер печатает адрес в локальной сети — по нему приложение открывается
с телефона (компьютер и телефон в одной Wi-Fi сети).

> Важно: открывать через `file://` нельзя — не заработают service worker
> и установка на домашний экран. Нужен http-сервер (или хостинг).

### Если телефон не открывает сайт

1. Телефон и компьютер должны быть в **одной Wi-Fi сети** (не в гостевой).
2. В адресной строке указывайте полный адрес с `http://`, например
   `http://192.168.1.208:4173` — без `http://` Safari ищет это в Google,
   а `https://` на локальном сервере не работает.
3. Окно с `start.bat` должно быть открыто: закрыли окно — сервер остановился.
4. Выключите VPN на телефоне (и «Частный DNS», если включён).
5. Проверьте, что IP компьютера не изменился: `ipconfig` → «IPv4-адрес».
   Роутер может выдать новый — тогда используйте новый адрес.
6. Если страница открывается, но пустая — внизу появится красная плашка
   с текстом ошибки, пришлите её скриншот.

Порт 4173 должен быть разрешён в брандмауэре Windows для `python.exe`
(при первом запуске Windows обычно спрашивает — нужно разрешить доступ
для «Частных сетей»).

### Доступ из интернета без хостинга (необязательно)

Если телефон не в домашней Wi-Fi или нужен HTTPS для установки как
приложения, дважды кликните **`start-public.bat`**. Он поднимет локальный
сервер и защищённый туннель, а в окне появится ссылка вида
`https://lingua-class-app.loca.lt`.

Первый раз браузер покажет страницу проверки: введите IP, написанный на
ней (это IP вашего компьютера), и нажмите **Continue**. Дальше ссылка
открывается сразу, а приложение можно установить на домашний экран.

> Ссылка работает, пока открыты окна `start-public.bat` и сервера и пока
> включён компьютер. Если туннель надолго остановить, адрес `*.loca.lt`
> может занять другой человек — тогда `start-public.bat` выдаст новый.
> Для постоянного адреса используйте хостинг (см. ниже).

## Установка на телефон

В самом приложении есть подсказка: **Профиль** → **📲 Установить приложение**.

### iPhone (Safari)

1. Откройте адрес приложения в **Safari** (лучше HTTPS-ссылку из `start-public.bat`).
2. Нажмите **Поделиться** → **На экран «Домой»**.
3. Запускайте как обычное приложение — без адресной строки, с иконкой.

### Android (Chrome)

1. Откройте адрес в **Chrome** (лучше HTTPS-ссылку).
2. Меню **⋮** → **Установить приложение** (или «Добавить на главный экран»).

После первого запуска по **HTTPS** все файлы кэшируются, и приложение
работает офлайн. По локальному `http://` иконка тоже добавится, но
офлайн-кэш и полноэкранный режим приложения iOS не включит.
Прогресс хранится на устройстве (`localStorage`), аккаунт не нужен.

## Сборка нативного приложения (App Store / Google Play)

PWA уже ставится на домашний экран. Если нужен именно нативный билд —
оберните тот же код в [Capacitor](https://capacitorjs.com):

```bash
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android
npx cap init LinguaClass com.example.linguaclass --web-dir=.
npx cap add ios
npx cap add android
npx cap sync
npx cap open android     # Android Studio
npx cap open ios         # Xcode (только macOS)
```

В `capacitor.config.json` укажите:

```json
{
  "appId": "com.example.linguaclass",
  "appName": "LinguaClass",
  "webDir": ".",
  "server": { "androidScheme": "https" }
}
```

Иконки: `icons/icon-512.png` (Android) и `icons/icon-1024.png` (iOS — при
необходимости сгенерируйте из `tools/make_icons.py`, добавив размер).

## Как добавить или изменить материал

Всё содержимое — в `content.js`. Один класс выглядит так:

```js
{
  id: "c7",
  title: "7 класс",
  level: "A2 · Уверенный",
  desc: "Неправильные глаголы, must / should, Present Perfect",
  goal: 40,
  units: [
    {
      title: "Путешествия",
      emoji: "✈️",
      grammar: "Past Simple (неправильные глаголы), сравнения",
      vocab: [["ticket", "билет"], ["hotel", "отель"]],
      sentences: [
        { en: "I bought two tickets.", ru: "Я купил два билета." }
      ]
    }
  ]
}
```

Добавили слова и фразы — приложение само соберёт из них 4 типа уроков
(слова, фразы, аудирование, проверка) и все типы упражнений.

Правила, которых стоит держаться:

- `vocab` — 8–12 пар на юнит, `sentences` — 6–8 фраз;
- в английских фразах — обычная пунктуация и заглавные буквы;
- переводы — естественный русский, без кальки.

После правок поднимите версию в `sw.js` (`VERSION`), чтобы обновить кэш
у уже установленных приложений.

## Технические детали

- **Без зависимостей и сборки**: три файла + ассеты.
- **Озвучка** — Web Speech API (`speechSynthesis`, голос `en-US`).
  На iOS работает после первого касания экрана; при отсутствии английского
  голоса произношение будет системным.
- **Звуки** — Web Audio API (синтез, без mp3-файлов).
- **Вибрация** — `navigator.vibrate` (только Android).
- **Прогресс** — `localStorage`, ключ `linguaclass.v1`. Сброс — в профиле.
- **XP**: 10 + 2 за верный ответ, +10 за урок без ошибок; тренировка без
  сердец даёт половину XP.
- **Сердца**: 5 штук, −1 за ошибку, +1 каждые 5 минут, пополнение за 20 💎.
- **Звёзды**: 3 — точность ≥ 90%, 2 — ≥ 70%, 1 — ниже.
- **Серия дней** растёт при занятии в новый день (пропуск дня сбрасывает её).

Для отладки в консоли браузера доступен объект `window.LinguaClass`
(`state`, `lesson`, `buildLesson`, `startLesson`, `go`, `reset`).
